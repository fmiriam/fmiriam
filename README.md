## Featured Project

### Nairobi Housing Price Prediction

An end-to-end machine learning and spatial analytics project using synthetic housing data.

**What I developed:**
- Exploratory data analysis of 3,000 simulated housing observations.
- Random Forest regression pipeline for housing price prediction.
- Model evaluation using random holdout testing and geographically grouped cross-validation.
- Spatial autocorrelation analysis using Moran's I.
- Interactive geographic visualizations.
- A deployed Streamlit application for exploring illustrative housing price predictions and model insights.

**Selected results:**
- Random holdout R²: **0.825**
- Random holdout MAE: **KES 3.16 million**
- Neighbourhood-grouped cross-validation mean R²: **−0.350**, highlighting limitations in geographic generalization.

**Technologies:** Python, pandas, scikit-learn, GeoPandas, Folium, PySAL, Streamlit.

🔗 [Explore the GitHub repository](https://github.com/fmiriam/nairobi-housing-price-prediction)

*This project uses entirely synthetic data. Predictions and geographic patterns are illustrative and do not represent actual Nairobi property valuations.*
